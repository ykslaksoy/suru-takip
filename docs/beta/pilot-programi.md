# Beta Pilot Programı — 50 Çiftlik

## Amaç
MVP'yi gerçek ahır koşullarında test etmek; offline, kilo, sağlık ve stok modüllerini doğrulamak.

## Katılım kriterleri
- 30+ baş koyun/keçi
- Konya, Kars, Van, Diyarbakır veya çevre iller (öncelik)
- 3 ay aktif kullanım taahhüdü

## Geri bildirim döngüsü
1. **Hafta 1:** İlk kayıt + 10 hayvan girişi
2. **Hafta 2:** Kilo + stok modülü testi
3. **Hafta 4:** Sağlık kaydı + AI veteriner denemesi
4. **Hafta 8:** NPS anketi + özellik önceliklendirme

## Metrikler
- Haftalık aktif kullanım > %30
- NPS > 40
- Kritik bug < 5 / pilot dönemi

## Uygulama içi kayıt
Menü → Beta Pilot → Kayıt sekmesi
